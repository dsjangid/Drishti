04 Real AI Model — Not Just a Demo

The model is real. You can run it right now.

The videos above show pre-rendered inference output. But दृष्टि ships a fully working YOLOv8x pothole detection model trained on 8,400+ annotated road frames. Upload any dashcam video and run it locally in under 3 minutes.

terminal

Run Locally — 3 Commands

Zero cloud dependency. Your video, your machine.

1. Clone & Enter
git clone https://github.com/dsjangid/Drishti && cd Drishti
2. Install Dependencies
pip install -r requirements.txt
3. Launch AI Lab (opens at localhost:8501)
bash scripts/run_ai_lab.sh
Model weights: The .pt file is gitignored (5.1 MB). Place best (16).pt in the project root. See models/README.md.
